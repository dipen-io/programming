Polymorphims patter - single colletion multiple types

building a notification system with sms and email

    email need : subject, from, to, htmlbody
    sms need: prodiver , body

a push notification need deviceToken, appBadgeCount, actionUrl

# Bad way ( The Frankenstein)
You try to stuff all fields into a single schema and make them optional:

    const badNotificationSchema = new Schema({
      userId: ObjectId,
      type: String, // 'email', 'sms', 'push'
      // --- Cluttered optional fields ---
      subject: String,     // Only for email
      phoneNumber: String, // Only for SMS
      deviceToken: String  // Only for Push
    });

# The Bad Way: Schema.Types.Mixed Without Validation
You use Mixed for everything:
    const looseNotificationSchema = new Schema({
      userId: ObjectId,
      type: String,
      payload: Schema.Types.Mixed // Wild-card object
    });


The Solution: Mongoose Discriminators

Discriminators are a way to achieve "Schema Inheritance". It allows you to have one shared collection in the database (called notifications), but treat different types of notifications as completely separate models with their own strict validation rules in your code.

    // 1. The Base Rule (All notifications get these)
    const notificationSchema = new Schema({
      userId: { type: Schema.Types.ObjectId, index: true },
      type: { type: String, enum: ['email', 'sms', 'push'] },
      read: { type: Boolean, default: false }
    }, { timestamps: true, discriminatorKey: 'type' });

    const Notification = model('Notification', notificationSchema);

    // 2. The EMAIL Rule (Adds subject and from)
    const EmailNotification = Notification.discriminator('email',
      new Schema({ subject: String, from: String })
    );

    // 3. The SMS Rule (Adds phoneNumber — NO subject, NO from!)
    const SmsNotification = Notification.discriminator('sms',
      new Schema({ phoneNumber: String })
    );

    // Saving an Email
    await EmailNotification.create({
      userId: "user123",
      type: "email",
      subject: "Hello!",
      from: "welcome@app.com"
    });

    // Saving an SMS
    await SmsNotification.create({
      userId: "user123",
      type: "sms",
      phoneNumber: "+1234567890" // 👈 Completely different field!
    });
